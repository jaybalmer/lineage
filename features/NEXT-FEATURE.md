## Standing rules (every feature session)

- `npx tsc --noEmit` must be clean before commit.
- One PR for the session. Push the branch, open the PR.
- Run the full **Ship sequence** in the repo `CLAUDE.md` before wrapping: surface every migration as copy-paste SQL, wait for Jay to apply it, prompt and wait for the merge, then log the ship. Do not treat PR-open as the end of the session.
- Append one entry to `bugs/SHIP-LOG.md` (schema at the top of that file). Feature sessions carry no `BUG-NNN`, so use `type: feature` with `ids: none` and a `scope:` slug. This is what lets the reconcile record feature ships. Leave `status: pending`; the reconcile flips it to `merged` once the PR lands.
- No em dashes anywhere you write.
